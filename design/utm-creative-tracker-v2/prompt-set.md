# Revised AI mockup prompt set

All ten images use the built-in image-generation tool in `ui-mockup` mode. They share a high-fidelity desktop application direction: white surfaces, navy text, signal-blue actions, pale blue selection, green validation, amber overrides, thin borders, restrained shadows, readable sans-serif typography, and no gradients, glass effects, fake browser chrome, logos, or watermarks.

## Shared requirements

- Show UTM parameters as controlled dropdowns rather than default free-text inputs.
- Show `utm_id` with four allowed values and an administered option-set surface.
- Represent one creative concept as a **Creative family** containing multiple **Renditions**.
- Include static, animated, HTML5 interactive, OLV, and CTV examples with multiple dimensions or durations.
- Inherit family UTM, destination, and testing defaults while exposing explicit per-rendition overrides.
- Use A/B, Single link, and Not applicable test modes; CTV can use Not applicable plus a QR asset.
- Validate interactive click tags/preview links and distinguish imported unknown UTM values from approved values.

## Input prompts

1. Guided wizard: active UTM and testing step, family rendition montage, open four-value `utm_id` dropdown, family destinations, inheritance and override summary.
2. Creative-first library: family library, selected rendition gallery with many shapes and behaviors, controlled family link/UTM inspector, inheritance and selected-rendition override.
3. Bulk matrix: grouped family/rendition rows, dropdown UTM cells, inheritance band, static/animated/interactive/video examples, A/B/Single/N/A scopes, selected-row inspector.
4. Linkage workspace: aligned four-zone flow from families to renditions to controlled rules to destinations and test scope, plus generated-link summary.
5. Smart import: uploaded deck/sheet/ZIP, human-reviewed family grouping, rendition detection, controlled UTM mapping, unknown-value issue, OLV/CTV overrides.

## Output prompts

1. Live dashboard: family-level KPIs and rows, expandable rendition QA, controlled UTM locks, inherited/overridden status, QR and A/B detail.
2. Excel preview: Family Summary, Rendition Index, URL Audit, UTM Dictionary, and Change Log tabs with one row per rendition/variant.
3. PowerPoint handoff: family overview slide with multi-format rendition montage, controlled UTM table, destination/test summary, and UTM/QR appendix options.
4. PDF approval: print-friendly creative-family page, rendition matrix, controlled selections, inheritance/override summary, approval sign-off.
5. Delivery hub: package outputs plus a family/rendition folder tree, controlled-dictionary version, override manifest, and validation totals.
