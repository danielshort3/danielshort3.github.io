Portfolio Project

Synthetic Digit Generator

Variational Autoencoder

Back to Portfolio
Data Science Machine Learning Python VAE

STAR Summary

Situation
I wanted to generate new handwritten digits, not just recognize them.
Task
Owned the end-to-end build, from implementation through the final deliverable.
Action
  • Trained a Variational Autoencoder (VAE) on MNIST (60,000 training digits) with a 20-dim latent space for up to 100 epochs.
Result
  • Generated new digits by sampling the learned latent space.
  • Saved the trained model so generation is a quick inference step.
Stack
Python · VAE · AWS · Docker
Status
Live interactive demo
Personal notes
Why I built it
I wanted to generate new handwritten digits instead of only recognizing them.
What surprised me
A smooth latent space made generation fast, but MNIST’s narrow style limits how representative the samples are of real handwriting.
What I’d try next
I’d compare latent sizes and add explicit fidelity and diversity evaluation before calling one model better.
Evaluation & tradeoffs
Status
Partial evaluation
Goal
Generate plausible MNIST-style digits by sampling a learned variational latent space.
Dataset
MNIST: 60,000 training digits and 10,000 test digits.
Split
The standard MNIST train and test datasets were used; the test loss also selected the saved checkpoint.
Baseline
Epoch 1 test loss was 107.9880 using the notebook’s binary-cross-entropy plus KL-divergence objective.
Decision
Saved the checkpoint with the lowest recorded test loss for the interactive generator.
Metrics
  • Best test loss: 93.5655 — Lowest recorded BCE + KL loss across the 100-epoch notebook run.
Limitations
  • The test set was used for checkpoint selection, so it is not an untouched final holdout.
  • No FID-style, classifier-based, diversity, or human-quality benchmark is published; generated samples remain a qualitative result.
