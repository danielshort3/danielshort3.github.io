# Game library icon generation prompts

Generated on September 6, 2026 with the built-in `image_gen` tool, one call per asset. The selected artwork was resized with Sharp to 256 × 256 PNGs for the site. The original white exterior is retained and uses the same scoped multiply blending as the project library icons. No image-generation CLI was used.

The five currently published games receive these icons in the game library and featured homepage cards. Existing gameplay and screenshot assets retain their separate `image` references.
