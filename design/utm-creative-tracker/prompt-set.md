# AI mockup prompt set

All ten assets were generated with the built-in image generation tool as high-fidelity, 16:9, implementation-ready website UI mockups.

## Shared visual direction

Realistic shippable web application UI using the current site's restrained visual language: white background, dark navy typography, signal-blue actions and selected states, pale blue and light gray surfaces, green validation, amber warnings, subtle one-pixel borders, restrained shadows, crisp sans-serif typography, generous whitespace, and no gradients, glassmorphism, fake browser chrome, logos, or watermarks.

## Input prompts

1. **Guided wizard:** A five-step campaign setup flow for Campaign, Partner, Creatives, Links & testing, and Review. Show creative upload rows for Display, OLV, and CTV, with an explicit three-state testing choice and a sticky campaign summary.
2. **Creative-first library:** A selected creative library on the left and link setup on the right. Show structured UTM fields, final URL preview, side-by-side Variant A/B destinations, allocation, validation, and CTV not-applicable behavior.
3. **Bulk trafficking matrix:** A calm expert grid with frozen Creative and Format columns; editable Destination, Source, Medium, Campaign, Content, Test mode, Variant B, and Status columns; grouped A/B rows; QR warnings; and a selected-row URL inspector.
4. **Linkage workspace:** A three-column relationship view aligning Creative assets, Link rules, and Destinations. Show A/B, Single, and N/A controls plus generated-link previews, without a tangled network diagram.
5. **Smart import and review:** Upload PowerPoint, Excel, and creative files; show parsed source files, extracted records with confidence, editable fields, source-cell lineage, A/B and CTV behavior, issues requiring review, and an explicit create-only-after-approval action.

## Output prompts

1. **Live operations dashboard:** Campaign KPIs, filters, creative thumbnails, partner and format, expandable A/B rows, CTV single-link plus QR status, QA checks, activity history, and export action.
2. **Excel workbook preview:** Website preview of an Audit XLSX with Trafficking, URL Audit, Creative Index, and Change Log tabs; frozen grid headers; creative thumbnails; variant destinations and tagged URLs; QR assets; and export checks.
3. **PowerPoint handoff:** Website preview with a slide filmstrip and large selected slide. Show a creative contact sheet, structured Variant A/B blocks, validated links, source/QR options, and dedicated CTV thumbnails without forced A/B.
4. **PDF approval report:** Print-friendly report preview with campaign metadata, creative blocks, A/B or single-link summaries, CTV QR treatment, approval fields, version notes, and report quality checks.
5. **Multi-format delivery hub:** One export center with rows for XLSX, PPTX, PDF, CSV, and a complete ZIP; preview/generate actions, package contents, naming convention, partner template, source references, and version history.
