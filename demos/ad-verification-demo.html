How it works

Each step is recorded, signed, and linked to the previous block. Checking those links makes later changes visible.

01

Hash event

Give each record a digital fingerprint. Change the record and its fingerprint changes too.

02

Link step

Put the signed event in a block that references the one before it.

03

Verify chain

Check fingerprints, signatures, and links. Flag a changed record and the steps that depend on it.

Demo only. Real cryptography; simulated events and validators in one browser. This checks record integrity, not whether a real person saw an ad or visited a destination. No advertising data is collected or sent.

Behind the demo

Four hash-linked blocks use SHA-256 fingerprints, Merkle roots, and ECDSA P-256 event signatures. Each block needs all three local demo approvals. A separately retained checkpoint detects missing or rewritten blocks. These are real calculations, but all keys and validators belong to the same browser—not an independently secured or distributed network.

Click any step to inspect its record. “Simulate change” changes the publisher’s report from 12,500 to 13,000 impressions without re-signing it. “Reset demo” restores the original signed records, rather than overwriting the evidence. No cryptocurrency, wallet, server, or account is involved.
