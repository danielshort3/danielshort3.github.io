# Preserved measurements before Cinder XP adjustment

This directory preserves the previous 1,575 measured scenarios and their comparisons, byte for byte. Cinder used the default XP multiplier of 1. The archived source files retain the previous authored publication/builders and the three runtime files later changed for NPC artwork. Source hashes in the original reports remain unchanged. The separate post-measurement visual verification documents 51 exact control replays; it does not rehash these measurements.

The parent directory will contain a fresh uniform matrix after Cinder's authored 0.93 multiplier and final renderer corrections. Offline scalar projections and rejected roster candidates are preserved as decision history, not observed final outcomes.
