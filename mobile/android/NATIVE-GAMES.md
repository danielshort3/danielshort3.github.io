# Native game coverage

The first Android game release implements the core-gameplay scope selected by the user. These are Kotlin game engines with Compose/Canvas rendering and native touch controls. They do not run HTML, JavaScript, a browser engine, or a WebView.

| Game | Implemented natively | Website features outside this first release |
| --- | --- | --- |
| Stellar Dogfight | Ten combat waves, free touch steering, auto-targeting weapons, three enemy approach behaviors, hostile projectiles, hull damage, the authored 6-second/16-second Overdrive, earned credits, persistent weapon/hull upgrades, saved active flight | Additional hulls/abilities, full enemy roster and boss mechanics, armory/loot rarity systems, contracts, factions, Astralite, salvage, multiple challenge modes, multiplayer/leaderboards |
| Ocean Wave Simulation | Animated native water surface using deep-water dispersion, wind/wave/light controls, drag-to-turn view, calm/storm presets, pause, persisted settings, reduced-motion default pause | GPU FFT/Ultra graphics, 3D shoreline/environment and underwater camera, procedural audio, session timer, full website rendering/scene presets |
| Project Starfall | Authored Fighter/Mage/Archer base stats, native side-scrolling Starfall Verge expedition, source-derived platform coordinates and gravity, touch movement/jump/attacks, cooldown power attack, Glassback encounters using authored sprite art, XP/levels, gold, 18-enemy objective, equipment drops/inventory/equipping, healing, revival, saved character/encounters | Other maps, advanced classes, skill trees, NPC dialogue, quest chains, crafting, full item/set/affix system, bosses/dungeons, world-map travel, cloud/shared saves |

All bundled art is copied from this repository's authored game assets; no new image generation was used. The app can play without downloading game art.

Games save into the app-private `native_games_v1` preferences. Native saves are independent of the website's browser storage. Active games checkpoint every five seconds, on backgrounding, when leaving a screen, and after deliberate changes. Lifecycle-scoped frame loops stop when their screen is removed or the activity is no longer visible. Stormbreak grants only its bounded offline gold estimate; other game timers do not run in the background. Auto-spins deliberately resume disabled after process recreation. Reset actions require confirmation.

Website feed updates refresh the catalog's names/descriptions, while changes to these native engines, bundled assets, or game balance require a rebuilt app. The app must not claim identical website mechanics or automatically ported future game features.

Pure unit tests cover dispersion validity, bounded movement after long frames, Overdrive duration, upgrade affordability, checkpoint restoration, boss/zone gating, capped offline rewards, reel adjacency/consumption/payout/deck rules, authored RPG stats, landing/double-jump prevention, gear ownership, and invalid save normalization. Emulator rendering/input/lifecycle checks belong to the app integration QA.
